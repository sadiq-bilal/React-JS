# 📈 Learning Progression

The projects will be developed in three stages.

### 🟢 Beginner

The initial projects will focus on understanding the fundamentals of React.

Topics include:

* JSX
* Components
* Props
* State
* Events
* Conditional rendering
* Lists and keys
* Basic Hooks
* Forms
* Basic styling

The goal is to become comfortable with building small React applications independently.

---

### 🟡 Intermediate

After understanding the fundamentals, I will create more practical applications with increased functionality.

Topics include:

* API integration
* `fetch()`
* `async/await`
* Loading states
* Error handling
* React Router
* Dynamic routes
* Forms and validation
* Reusable components
* Context API
* More advanced state management

The goal is to build applications that behave more like real-world web applications.

---

### 🔴 Advanced

The advanced stage will focus on larger and more realistic applications.

Topics include:

* Complex state management
* Redux Toolkit

The goal is to develop the ability to design and build **production-style React applications**.

# 💻 Running the Projects

Each project may have its own setup instructions.

Generally:

```bash
npm install
```

Then start the development server:

```bash
npm run dev
```

The project can then be opened using the local development URL provided by Vite.
