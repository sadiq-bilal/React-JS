# Expense Tracker

A simple **Expense Tracker** application built using **React.js**.
This project helps users manage their income and expenses and view the total balance.

## 🚀 Features

* Add new expenses
* Edit expenses
* Delete expenses
* Select expense category
* Add expense date
* Calculate total income
* Calculate total expenses
* Calculate remaining balance
* Prevent balance from becoming negative
* Display "No Expenses Yet" when there are no expenses

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* React Hooks (`useState`)

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Go to the project folder:

```bash
cd ExpenseTracker
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.
