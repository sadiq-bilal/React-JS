# 🛒 ShoppingCart_App

ShoppingCart_App is an **intermediate-level React project** that demonstrates how a basic e-commerce shopping cart works.

The application allows users to browse products, add products to the cart, change product quantities, remove products, and view the total price of the selected items.

This project is mainly built to practice **React components, props, state management, array methods, event handling, and conditional rendering**.

---

## 🚀 Features

* Display a list of products
* Add products to the shopping cart
* Increase product quantity
* Decrease product quantity
* Remove products from the cart
* Prevent duplicate cart items
* Calculate total number of cart items
* Calculate total cart price dynamically
* Responsive user interface
* Reusable React components
