# Melody

A music streaming web app inspired by YouTube Music, built with React, Vite and Tailwind CSS.

## Features

- Home, search, library, album, artist and playlist pages
- Persistent bottom player that keeps playing while you navigate
- Play/pause, next/previous, seeking, volume, mute, shuffle, repeat
- Queue (add any song from a song row)
- Liked songs and recently played saved in localStorage
- Keyboard shortcuts: `Space` play/pause, `N` next, `P` previous
- Responsive layout with a sidebar on desktop and bottom navigation on mobile

## Stack

React 18, Vite, Tailwind CSS 4, React Router, Framer Motion, Lucide icons.
Demo audio comes from SoundHelix and artwork from Picsum.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and import the repo on Vercel. `vercel.json` already handles client-side routing.
